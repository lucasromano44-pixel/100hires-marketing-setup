### 3. Encountered Issues & Professional Troubleshooting

#### Issue 1: IDE Shortcut & Extension Catalog Restriction (OS-Level)

- **Symptom:** The universal extension shortcut `Ctrl + Shift + X` was entirely unresponsive. Manual catalog searches for core extensions returned zero results, blocking standard setup procedures.
- **Root Cause Analysis:** The local workstation utilizes a customized, gaming-optimized operating system (Windows Kernel OS build). These modified environments strip background telemetry, alter shortcut listeners, and disable network connectivity layers, directly restricting Cursor's internal marketplace API.
- **Resolution:** Switched to an infrastructural workaround utilizing the GitHub Web Workspace to guarantee delivery within the deadline. Path variables were subsequently audited to repair local application behaviors.

#### Issue 2: Terminal Execution Failure for CLI Commands

- **Symptom:** Attempting to run `npm install` resulted in a critical `CommandNotFoundException` error.
- **Root Cause Analysis:** The stripped nature of the customized OS lacked a Node.js runtime environment completely.
- **Resolution:** Downloaded and executed the official Node.js LTS MSI installer, injecting the binaries into the system's PATH variables to achieve global installation of the CLI tool.

#### Issue 3: Authentication Gate for CLI Access

- **Symptom:** The CLI tool restricted login methods, demanding an active paid Tier or a Commercial API profile with pre-funded credits.
- **Root Cause Analysis:** Anthropic's preview implementation enforces active commercial metering profiles to manage traffic.
- **Resolution (Professional Cost-Control Policy):** No personal financial resources were deployed for a pre-onboarding technical assessment. The local system has been verified and fully configured, leaving the local CLI framework fully prepared to accept enterprise API keys upon workflow allocation.

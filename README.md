## 3. Encountered Issues & Professional Troubleshooting

### Issue 1: IDE Shortcut & Extension Catalog Restriction (OS-Level)
* **Symptom:** The universal extension shortcut `Ctrl + Shift + X` was entirely unresponsive inside the editor. Furthermore, manual catalog searches for core extensions like "Claude Code" or "Spanish Language Pack" returned zero results, blocking standard setup procedures.
* **Root Cause Analysis:** The local workstation utilizes a highly customized, gaming-optimized operating system (**Windows Kernel OS build**). These modified environments aggressively strip background telemetry, alter standard shortcut listeners, and disable secondary network connectivity layers to save system resources, which directly restricted Cursor's internal marketplace API.
* **Resolution:** Switched to an infrastructural workaround by utilizing the **GitHub Web Workspace** to guarantee delivery within the 48-hour deadline. Once the immediate delivery was secured, system path variables were manually audited to repair local application behaviors.

### Issue 2: Terminal Execution Failure for CLI Commands
* **Symptom:** Attempting to run `npm install -g @anthropic-ai/claude-code` via the command line resulted in a critical `CommandNotFoundException` error, stating that 'npm' was not recognized.
* **Root Cause Analysis:** Due to the stripped nature of the customized operating system, the system lacked a Node.js runtime environment altogether, meaning the machine had no capacity to parse or install developer packages.
* **Resolution:** Downloaded and executed the official Node.js LTS MSI installer, ensuring the binaries were injected into the system's PATH environment variables. After a complete console environment reset, the global installation of the CLI tool was achieved successfully.

### Issue 3: Authentication Gate for CLI Access
* **Symptom:** Upon initializing the CLI tool locally, the application restricted standard login methods, demanding an active paid Tier (Pro/Max subscription) or an immediate Commercial API Billing profile with pre-funded credits.
* **Root Cause Analysis:** Anthropic's preview implementation for command-line interfaces enforces active commercial metering profiles to manage traffic, preventing standard free tier consumer accounts from authenticating via terminal web links.
* **Resolution (Professional Cost-Control Policy):** In alignment with standard corporate infrastructure practices, no personal financial resources were deployed for a pre-onboarding technical assessment. The local system has been verified, hardened, and fully configured with Node.js and the tool’s packages, leaving the local CLI framework fully prepared to accept enterprise API keys or official corporate testing environments upon workflow allocation.
